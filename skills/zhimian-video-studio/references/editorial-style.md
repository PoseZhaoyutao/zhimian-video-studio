# 智面引擎 Editorial Style

## Script Shape

Use this structure for technical interview episodes:

1. 面试原题：3秒内抛出具体问题。
2. 直觉解释：用一句工程直觉降低门槛。
3. 底层原理：解释机制、公式、数据结构或系统 tradeoff。
4. 连续追问：给 2–3 个面试官会继续问的问题。
5. 高分回答骨架：给可复述的回答顺序。
6. 常见错误：指出低分回答为什么不行。

## Platform Copy

### 小红书

- 标题偏搜索：技术关键词 + 结果承诺。
- 描述用“问题/步骤/结论/收藏提示”。
- 5–8 个精准标签。

### 抖音

- 标题短，前半句制造冲突。
- 描述直接给结论，再抛一个互动问题。
- 3–5 个高相关标签。

### B站

- 标题信息完整，适合搜索和收藏。
- 描述包含知识点、适用人群、AI配音声明。
- 5–7 个技术分区标签。

## Source Rules

Use primary sources for factual claims. If the topic may have changed recently, verify before scripting. Never present uncertain or disputed guidance as the only correct answer.
