# 智面引擎 Editorial Style

## Script Shape

Use this structure for technical interview episodes:

1. **Hook（前 3 秒，最关键）**：用冲突/数字/痛点范式，首句必含钩子词。禁止用"面试官问…""今天讲…""这一期我们…"开场（数据证明这类开场前 3 秒大量秒退）。四种范式任选其一：
   - 范式 A｜冲突反差：「…90% 的人开口就答错 / 一开口就暴露」
   - 范式 B｜数字冲击：「…硬省 8 倍显存 / 175B 单卡 OOM」
   - 范式 C｜痛点共鸣：「背了三遍还是混？/ 被追问就哑了？」
   - 范式 D｜悬念利益：「大厂必问，因为它一次筛掉一半候选人 / 45 秒讲透」
   - 钩子词清单（首句必带至少一个）：`90% / 开口就错 / 被追问就哑 / 硬省X倍 / OOM / 必问 / 筛掉一半 / 45秒讲透 / 别只背 / 一条线讲透`
2. 直觉解释：用一句工程直觉降低门槛。
3. 底层原理：解释机制、公式、数据结构或系统 tradeoff。
4. 连续追问：给 2–3 个面试官会继续问的问题。
5. 高分回答骨架：给可复述的回答顺序。
6. 常见错误：指出低分回答为什么不行。

## Platform Copy

### 标签四层配方（所有平台必用）

标签必须分四层，缺 L4 流量词是历史视频推荐流量起不来的直接原因：

| 层 | 内容 | 数量 | 说明 |
|---|---|---|---|
| L1 品牌词 | `#智面引擎` | 1 | 固定，三平台都带 |
| L2 必带核心 | `#面试 #AI算法` | 2 | 固定，符合 global_tags 规则 |
| L3 选题技术词 | 本期具体概念 | 1-2 | 如 `#ZeRO #分布式训练` |
| L4 流量/场景词 | 见下方词池 | 3-4 | 从池中选，命中推荐流量池 |

**L4 流量/场景词池（当前视频完全缺失，是改进重点）：**
- 求职节点：`#秋招 #春招 #校招 #25届 #26届 #求职`
- 岗位场景：`#算法岗 #大模型面试 #算法工程师面试 #后端面试`
- 内容类型：`#面试经验 #八股文 #大厂面试题 #面试高频 #面经`
- 情绪/泛流量：`#涨知识 #干货分享 #程序员 #程序员日常`

**禁止使用**：`#后端 #大厂面试 #程序员 #AI学习` 作为非后端主题的标签（与 AI 算法定位冲突，历史数据证明拉低推荐）。

### 小红书

- 标题偏搜索：技术关键词 + 结果承诺；高点击率标题用"具体名词｜反差钩子"两段式（竖线分隔）。
- 描述用"问题/步骤/结论/收藏提示"。
- 8-9 个标签：L1+L2+L3(2)+L4(4-5)。

### 抖音

- 标题短，前半句制造冲突。
- 描述直接给结论，再抛一个互动问题。
- 5-6 个标签：L1+L2+L3(1)+L4(2-3)。抖音算法对堆叠标签降权，5 个左右最佳。

### B站

- 标题信息完整，适合搜索和收藏。
- 描述包含知识点、适用人群、AI配音声明。
- 8-10 个标签：L1+L2+L3(2)+L4(4-5)+英文词（B站搜索导向，可带英文如 ZeRO/DeepSpeed）。

### 评论引导（所有平台必加）

文案末尾必须加一句评论引导（解决"评论 0"问题）。范式：
- 「你被问过哪道 {主题} 的题被卡住？评论区扣出来，下期直接拆。」
- 「{主题} 你最怕被追问什么？评论区告诉我。」

## Source Rules

Use primary sources for factual claims. If the topic may have changed recently, verify before scripting. Never present uncertain or disputed guidance as the only correct answer.
