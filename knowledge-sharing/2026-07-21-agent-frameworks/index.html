LangGraph
LangChain · 状态图架构 · ⭐ 10K+
  • StateGraph：有向图，节点=处理步骤，边=条件路由
  • 循环图：支持Cyclic Graph，Agent自主迭代的关键
  • 状态持久化：Checkpointer断点恢复
  • 人工介入：Human-in-the-loop原生支持
来源: LangChain官方文档 langchain-ai.github.io/langgraph/
设计目标: 可控、可调试的生产级Agent

AutoGen
Microsoft Research · 对话驱动 · ⭐ 54K+

  • 代码执行：内置Docker沙箱，可写代码并运行

  • MAF合并：2025末与Semantic Kernel合并
来源: Microsoft Research官方博客; github.com/microsoft/autogen
弱点: 对话流程不易精确控制，状态管理不如LangGraph显式

CrewAI
CrewAI Inc. · 角色编排 · ⭐ 25K+

  • 两种编排：顺序(Sequential) + 层级(Hierarchical)
  • 任务分配：Manager Agent负责任务分派
  • 平台进化：2025年升级为Agentic AI平台
来源: CrewAI官方文档 docs.crewai.com; github.com/crewAIInc/crewAI

选型建议
没有最好，只有最适合
LangGraph
复杂流程控制 · 循环迭代 · 精确状态管理
需要条件分支、断点恢复、人工介入的生产级Agent。配合LangSmith可观测性，适合严肃工程。
AutoGen / MAF
多Agent协作对话 · 代码生成与执行
核心场景是多Agent讨论、代码编写和运行。微软生态用户首选，MAF统一了Agent开发栈。
CrewAI
角色分工 · 快速原型 · 直觉式开发
团队偏好角色扮演式的任务分配，需要快速搭建多Agent协作流水线，不需要复杂流程控制。
OpenAI API
简单集成 · 不在意生态锁定
只需几行代码接入AI能力，不需要多Agent、不需要自定义流程，接受OpenAI生态绑定。
